# Кафе «Домашняя кухня» — сайт

Статический сайт: HTML, CSS и JavaScript. Подходит для GitHub Pages.

## Как добавить свои фотографии
1. Откройте папку `assets`.
2. Добавьте фотографию блюда с именем `food.jpg` — она появится на первом экране.
3. Для замены картинки меню замените `assets/menu.jpg` своим файлом (с тем же именем).

Можно добавить и другие фото, меняя `src` в `index.html`.

## Публикация через GitHub
1. Создайте новый репозиторий на GitHub.
2. Загрузите все файлы и папку `assets` из архива (не сам архив).
3. В репозитории откройте **Settings → Pages**.
4. В разделе Build and deployment выберите **Deploy from a branch**, ветку `main`, папку `/ (root)`, затем Save.
5. Через несколько минут GitHub покажет адрес сайта.

Контакты и график уже добавлены. Фотографии — заглушка, которую можно заменить.
